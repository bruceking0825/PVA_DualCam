## Previous Boundary Tracking Option

- Added the following `[OnlineVision]` setting:

```ini
body_edge_use_previous_boundary_y = [1]
```

- Behavior:
  - `1`: use the previous valid Body/Crown boundary Y to restrict the next-frame search window.
  - `0`: ignore the previous boundary and search the full valid region on every frame.
- The stored `previous_boundary_y` remains a dynamic measurement value; only its use is controlled by configuration.
- Added `body_edge_previous_tracking_active` to measurement diagnostics to indicate whether previous-frame tracking was actually active for the current frame.
- The setting uses the shared `ConfigManager` boolean conversion and takes effect immediately through the existing `OnlineVision` update path.
