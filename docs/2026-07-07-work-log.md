## MATLAB Model Notes

- Explained `calibrationb.m` lines 255-283:
  - Converts `posc1/posc2` rotation angles from degrees to radians.
  - Builds `Ac1/Ac2` from rotation and translation.
  - Saves unscaled `Ac1p/Ac2p`, then scales the first two rows of `Ac1/Ac2` by focal length.
  - Computes camera origin and lens center positions in world coordinates.
- Explained:
  - `WPco = -R' * [tx; -ty; tz]`
  - `LCc = [-cpx*Sx/NDX/Asp; -cpy*Sy/NDY; Foc]`
  - `cvctr = R' * LCc + WPco`
- Confirmed that the mathematically consistent form for both cameras is:

```matlab
cvctr = Acp(:,1:3)' * LCc + WPco;
```

## XYZproj / XYZproj2

- Compared `XYZproj.m` and `XYZproj2.m`.
- `XYZproj.m`:
  - Uses externally supplied `A`.
  - Uses the Heikkila-style `B1/B2/B3/B4` terms.
  - Corresponds to the Python `project_xyz_with_matrix()` path.
- `XYZproj2.m`:
  - Builds `A = P * M` from `pos` and focal length.
  - Uses standard point projection with `[X,Y,Z,1]`.
  - Corresponds to the Python `project_xyz()` path.
- Clarified that both functions share the same later distortion and pixel conversion formula.
