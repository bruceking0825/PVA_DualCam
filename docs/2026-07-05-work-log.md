## Combined Image Splitting

- Updated `PageCalibration._split_combined_image()` in `src/modules/page_calibration.py`.
- Previous behavior split the combined image into left and right halves only.
- New behavior matches the MATLAB logic:

```matlab
A1 = flipud((A(:,1:sizeA(2)/2))');
A2 = flipud((A(:,(sizeA(2)/2+1):sizeA(2)))');
```

- Python implementation now:
  - Splits the combined image by width.
  - Transposes each half.
  - Flips each transposed half vertically.
  - Handles both grayscale and color images.

## World Coordinates

- Updated `PageCalibration._world_xy_point()` in `src/modules/page_calibration.py`.
- New coordinate convention:
  - Origin is the center of the initial 2x2 seed corners.
  - Increasing column index is positive X.
  - Decreasing row index is positive Y.
  - Grid spacing still uses `square_size_mm`.

Current formula:

```python
center_row = self.settings.board_rows // 2 + 0.5
center_col = self.settings.board_cols // 2 + 0.5
x = (col - center_col) * self.settings.square_size_mm
y = (center_row - row) * self.settings.square_size_mm
```

`z` is unchanged and is still generated from the sample slot:

```python
z_mm = slot_index * z_step_mm
```
