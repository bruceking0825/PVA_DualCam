## Stereo Reconstruction Discussion

- Confirmed that if one physical point is observed in both camera views, its 3D/world coordinate can be recovered by stereo triangulation.
- Compared two possible approaches:
  - Standard linear triangulation using two `3x4` projection matrices.
  - Nonlinear inverse solving using the existing legacy forward projection function.
- Clarified that the current MATLAB legacy model is more complex than a standard pinhole projection:
  - It uses `Ac1/Ac2` together with `par1/par2`.
  - It includes quadratic coordinate terms.
  - It applies legacy distortion and pixel conversion through `project_xyz_with_matrix()`.
- Concluded that nonlinear inverse solving is the safer method for this project.

## DLT Notes

- Explained `_dlt_world_guess()`:
  - It assumes a standard pinhole model:

```text
s * [u, v, 1]^T = P * [X, Y, Z, 1]^T
```

  - It builds a `4x4` homogeneous linear system from the two image points.
  - It solves the homogeneous system with SVD.
  - It converts the homogeneous result back to `X/Y/Z`.
- Found that this assumption does not match the current legacy model.
- Example discussed:
  - Expected world point: `(0, 0, 0)`
  - `point1 = [2675, 1975]`
  - `point2 = [2668, 2783]`
  - DLT result: approximately `[27.2, -415.9, 983.8]`
- Conclusion:
  - The DLT result is not a reliable final answer for this project.
  - It should only be treated as an optional initial guess, and should be rejected if its legacy-model reprojection error is too large.
