# 2026-08-02 Work Log

## Summary

- Simplified runtime configuration and separated runtime settings from shared measurement parameters.
- Corrected online/offline camera ROI ownership and calibration-coordinate origin handling.
- Added stereo frame delta display to the Home Results tab.
- Refactored `PageHome` and `PageCamera` to remove dead code and separate UI, worker, and diagnostic responsibilities.
- Renamed shared online/offline measurement types, modules, and state files from `Online*` to `Measurement*`.

## Configuration Cleanup

- Removed obsolete `[Runtime]` entries:
  - `runtime_mode`
  - `auto_start`
  - `offline_image_path`
  - `offline_stage`
- Runtime mode is now controlled by the Home page Online/Offline toggle.
- Offline stage is controlled by the Home stage buttons and defaults to Neck.
- Offline images are loaded only from `offline_image_dir`; the single-image fallback was removed.
- Automatic startup remains enabled as fixed application behavior rather than a configurable option.
- Renamed the former `[Online]` section to `[Runtime]`.
- Renamed the former `[Global]` section to `[Measurement]` instead of merging it into `[Runtime]`:
  - `[Runtime]` contains lifecycle, file, timing, and stereo synchronization settings.
  - `[Measurement]` contains shared brightness, physical range, reprojection, and filtering settings.
- `[Measurement]` changes take effect on the next frame without restarting runtime workers.

## Camera ROI And Coordinates

- Moved both acquisition ROI settings to `[Camera]`:

```ini
offline_crop_roi = [0,0,5120,5120]
online_crop_roi = [1700,0,1600,5120]
```

- `offline_crop_roi` is used by manual and calibration camera capture.
- `online_crop_roi` is written directly to both production cameras for Home online capture.
- Removed software crop settings and the obsolete offline origin parameters from `[Runtime]`.
- Calibration-coordinate origin is taken directly from the `x,y` values of `online_crop_roi`.
- Offline composite images are processed at their original split-image size without an additional software crop.
- ROI values are included in the measurement-state geometry fingerprint.

## Measurement Naming Migration

Shared code is used by both online and offline measurement, so the following names were changed:

```text
online_state.json              -> measurement_state.json
OnlineConfig                   -> MeasurementConfig
ConfigManager.online           -> ConfigManager.measurement
OnlineStage                    -> MeasurementStage
online_core/                   -> measurement_core/
online_workers.py              -> measurement_workers.py
test_online_core.py            -> test_measurement_core.py
```

- Shared measurement parameters are now accessed through:

```python
config_manager.measurement.common
```

- Names that genuinely refer only to online acquisition were retained, including:
  - `online_crop_roi`
  - `online_camera_*` signals
  - `start_online_cameras()`
  - `latest_online_frames`
- Home page window title was changed from `Online Measurement` to `Stereo Measurement`.
- `measurement_state.json` keeps the existing state data and schema version.
- Both legacy and current runtime state filenames are ignored by Git because an older running application instance can recreate `online_state.json` until it is restarted.
