# 2026-07-24 Work Log

## Summary

- Reduced stereo triangulation work by using the DLT estimate as the primary nonlinear-solver initial value and retrying from zero only when the first solve fails.
- Simplified Neck measurement to use the fitted axis-aligned ellipse only.
- Changed Neck melt level to use the stereo-reconstructed geometric lower ellipse vertices.
- Changed Neck diameter to use the mean major-axis length from both camera ellipses with a configurable pixels-per-millimeter ratio.
- Improved Crown meniscus detection by excluding columns without a meniscus response before row scoring.
- Changed Crown row-peak selection to use the lowest significant local peak.

## Stereo Triangulation

- `StereoGeometry.triangulate()` no longer solves unconditionally from both the DLT and zero initial guesses.
- The nonlinear solver now:
  1. Solves from the DLT initial estimate.
  2. Returns that result when it converges to finite coordinates.
  3. Retries from `[0, 0, 0]` only when the DLT solve is unavailable or invalid.
- The existing `trf` method, `soft_l1` loss, `f_scale`, and iteration limit remain unchanged.
- An isolated `neck1_m.bmp` benchmark reduced the measured cycle from approximately `395 ms` to approximately `119 ms`.

## Neck Melt Level And Diameter

- `_find_ellipse()` now always sets the Neck lower point from `_ellipse_lower_point(ellipse)`.
- The lower ellipse vertices from Camera 1 and Camera 2 are stereo-triangulated.
- Neck melt level is calculated as:

```text
melt_level_mm = lower_vertex_xyz.z + world_z_offset_mm
```

- Added the following configuration:

```ini
neck_pixels_per_mm = [24]
```

- Neck diameter is calculated directly from the mean fitted major-axis length:

```text
diameter_mm =
    (major_axis_camera1_px + major_axis_camera2_px)
    / 2
    / neck_pixels_per_mm
```

- `mm_per_pixel` is initialized from `1 / neck_pixels_per_mm`.
- Real `neck1_m.bmp` verification produced:

```text
Camera 1 major axis: 191.9489 px
Camera 2 major axis: 192.2341 px
Diameter:              8.0038 mm
Melt level:           21.6277 mm
```

## Crown Meniscus Column Filtering

- `_find_meniscus_arc()` now calculates the maximum negative-gradient response for each candidate column.
- Columns below the existing `body_edge_score_mean_factor` threshold are removed before row scoring.
- Small gaps between active columns are grouped for segment selection.
- Only the active segment containing, or nearest to, the projected center is retained.
- The following operations now use only the selected meniscus columns:
  - `row_scores`
  - seed-row selection
  - per-column edge extraction
  - robust quadratic fitting
- Coverage is evaluated relative to the selected column segment, allowing a small Crown meniscus to occupy only part of the reflector width.

## Crown Row Peak Selection

- Replaced direct `np.argmax(row_scores)` selection with `_last_peak_index()`.
- Local peaks are detected with `scipy.signal.find_peaks()`.
- A significant peak must be at least `50%` of the global maximum row score.
- When multiple significant peaks exist, the peak with the largest row index is selected.
- If no significant local peak exists, selection falls back to the global maximum.
- This avoids choosing small trailing noise peaks while preferring the lowest meaningful meniscus transition.
