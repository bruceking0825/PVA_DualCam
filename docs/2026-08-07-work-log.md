# 2026-08-07 Work Log

## Automatic Exposure Persistence

### Requirement
- Online automatic exposure should keep adjusting camera exposure during runtime.
- The learned exposure should survive application restart and be reused on the next Online startup.
- `cnf.ini` should remain the static operator configuration source and should not be rewritten by runtime auto exposure.

### Design
- `initial_exposure_camera1` and `initial_exposure_camera2` in `cnf.ini` are initial/fallback values.
- Runtime learned exposure is stored independently in `src/camera_state.json`.
- Online startup loads exposure in this order: `camera_state.json`, then cnf initial exposure fallback, then min/max clamp.
- Calibration/manual exposure changes do not update the Online exposure memory.
- Online auto exposure is still active only in `idle` and `neck`; other stages keep the latest exposure unchanged.
