## Single Camera Owner

- Made `PageCamera` the only page that owns `CameraManager` and `CameraDevice` objects.
- Removed gxipy, camera enumeration, open, stream, stop, and close operations from `PageCalibration`.
- Added cross-page signals:

```python

calibration_camera_stop_requested
calibration_camera_started
calibration_camera_stopped
calibration_camera_failed
camera_frame_captured
```

- The Calibration page now:
  1. Emits a start request when switching to `Alive`.
  2. Receives `(camera_role, image)` frames from `PageCamera`.
  3. Saves the last frames when switching to `Frozen`.
  4. Emits a stop request so `PageCamera` stops streams and closes both cameras.
- `PageCamera` applies exposure, gain, image size, offsets, and continuous trigger mode before starting both streams.
- Calibration streaming does not run the PageCamera image-processing pipeline.
- Frames are copied before crossing the SDK callback boundary so reused SDK buffers cannot corrupt displayed images.

## Camera Access Recovery

- Investigated the `CCP SetPrivilege / Access denied {-1005}` error using `docs/python接口开发说明书.pdf`.
- Confirmed the documented normal release sequence:

```python
cam.stream_off()
cam.close_device()
```

- Added one-time recovery in `CameraDevice.open()`:
  1. Attempt to open normally.
  2. Detect only access-denied errors (`Access denied`, `-1005`, `SetPrivilege`, or `CCP register`).
  3. Execute `GxResetDeviceModeEntry.RECONNECT` using the GigE MAC address.
  4. Re-enumerate devices.
  5. Retry opening once.
  6. Raise the retry error without entering a loop if it still fails.
- Other SDK or network errors do not trigger reconnect.
