# 2026-07-26 Work Log

## Summary

- Added a dedicated Process tab to PageHome for live algorithm diagnostics.
- Added detailed rejection reasons and preserved partial process data when a detector returns early.
- Separated Crown and Body edge parameters and changed Crown column filtering to a maximum-based threshold.
- Changed reflector side-boundary filtering to a maximum-based threshold while retaining mean and maximum diagnostics.
- Simplified image overlays and standardized the Crown/Body reference markers.
- Removed `world_z_offset_mm`; measurement Z values now use the calibrated world coordinate directly.

## PageHome Process Data

- Reorganized the right panel into `Results`, `Process`, and `Log` tabs so diagnostics no longer compete with the measurement controls for vertical space.
- Added a three-column process tree:
  - `Name`
  - `Value`
  - `Unit`
- Process values are grouped into Camera 1, Camera 2, Stereo, Runtime, and Algorithm sections.
- Diagnostic keys are converted into readable labels, and `_mm`, `_px`, `_ms`, and `_deg` suffixes are displayed as units.
- Numeric arrays are formatted compactly and full values remain available through tooltips.
- Corrected the process-table header sizing so the Name/Value and Value/Unit boundaries resize in the expected direction.

## Partial Diagnostics And Failure Reporting

- Added process-data collectors to the Reflector, Neck, Crown, and Body detectors.
- Process data is merged into `MeasurementResult.diagnostics` before checking whether a detector succeeded.
- A frame that fails partway through processing therefore still displays all values calculated before the rejection, including:
  - ROI and search ranges
  - score means and maxima
  - active thresholds
  - candidate and fitted-point counts
  - robust-fit residual limits
  - coverage and sagitta
- Replaced silent detector `None` returns with explicit reasons containing the relevant measured value and configured limit.
- Stereo failures identify Camera 1 and Camera 2 independently.
- Every invalid `MeasurementResult` is written to the PageHome Log tab while the last valid measurement values remain unchanged.

## Reflector Boundary Threshold

- Reflector side boundaries continue to be searched from the image center toward the two sides.
- Replaced the former mean-based threshold:

```text
side_score_mean * reflector_side_score_mean_factor
```

- The current threshold is:

```text
side_score_maximum * reflector_side_score_max_factor
```

- Current configuration:

```ini
reflector_side_score_max_factor = [0.5]
```

- `side_score_mean`, `side_score_maximum`, the resulting threshold, and left/right candidate counts are exposed in the Process tab for both cameras.

## Crown And Body Separation

- Crown and Body now use separate search and fitting parameters.
- Crown-specific configuration includes:

```ini
crown_edge_column_max_factor
crown_edge_use_previous_boundary_y
crown_edge_search_half_height_ratio
crown_edge_horizontal_margin_ratio
crown_edge_bottom_margin_ratio
crown_edge_fit_residual_ratio
```

- Crown column filtering calculates the maximum valid negative-gradient response in each column.
- The active-column threshold is:

```text
column_strengths_maximum * crown_edge_column_max_factor
```

- `column_strengths_mean` and `column_strengths_maximum` are both displayed as diagnostics.
- Crown coverage remains available for diagnostics but is no longer a validity condition.
- Body retains its separate per-column `maximum brightness - offset` search and still applies `body_edge_min_coverage_ratio`; no Crown global-strength factor is reused by Body.

## Overlay Changes

- Removed the full-image ROI frame, growth ROI, status text, and detector text labels from both camera views.
- Removed labels for Reflector model, Neck center, and Crown/Body boundary.
- Retained the actual fitted contours, curves, lines, and fixed-screen-size cross markers.
- Reflector left boundary, right boundary, and bottom curve now use the same blue color.
- The three saved Reflector boundaries remain visible during Crown and Body processing, including frames where meniscus detection later fails.
- Crown and Body marker colors are:
  - Initial Neck center: magenta cross (`#FF00FF`)
  - Current projected axis center: green cross (`#00FF00`)
  - Calculated meniscus boundary: red cross (`#FF0000`)

## World Z Coordinates

- Removed `world_z_offset_mm` from:
  - `VisionSettings`
  - `cnf.ini`
  - Neck measurement
  - Crown/Body measurement
  - projected-axis center recovery
  - tests
- Neck melt level and reflector elevation now directly use the triangulated world Z coordinate.
- Crown/Body melt level now directly uses the mean Z coordinate of the reconstructed axis center and boundary point.
- This supersedes the offset-based formulas documented in the `2026-07-24` work log.
