## Calibration Flow Comparison

- Compared `src/run_calibration.py` with `PageCalibration.calibrate()`.

```python
calibrate_legacy_camera(config, cam1_data)
calibrate_legacy_camera(config, cam2_data)
build_stereo_export(config, result1, result2)
```

- Main differences are before and around the shared core:

  - UI calibration validates missing slots and runs asynchronously in `CalibrationWorker`.
  - UI parameters come from `cnf.ini`; command-line parameters come from script arguments.
