## Bozhong OPC UA NodeId Support

- Updated `[PLC]` config to use the Bozhong OPC UA server interface Node IDs:

```ini
mode_node = [http://UA1;i=3]
shoulder_transition_node = [http://UA1;i=2]
melt_level_node = [http://UA1;i=7]
diameter_node = [http://UA1;i=5]
reflector_elevation_node = [http://UA1;i=6]
hr_node = [http://UA1;i=4]
```

- Added NodeId normalization in `src/online_core/plc.py`.
- The program now converts namespace URI style Node IDs to namespace-index Node IDs after connection:

```text
http://UA1;i=3 -> ns=1;i=3
```

- This avoids sending `nsu=http://UA1;i=3` directly to the server, which can cause `BadEncodingLimitsExceeded` on some OPC UA server implementations.
- `mode` and `shoulderTransition` are configured as `REAL` in Bozhong, so read conversion now supports:
  - `float -> int` for mode.
  - `float/string -> bool` for shoulder transition.
