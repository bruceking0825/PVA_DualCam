## Neck ROI Optimization

- Added `[Neck]` parameters:
  - `neck_start_search_ratio`
  - `neck_stop_search_ratio`
- `_find_reflector_bottom` now crops the image height using existing reflector bottom search ratios before blur/Sobel processing.
- `_find_ellipse` now accepts a vertical ROI from the new Neck search ratios.
- ROI width remains the full image width.
- Detection results are translated back to original image coordinates before being returned, so triangulation and overlays continue to use full-image coordinates.
