## Image Utility

- Added `tools/extract_camera_pair.py`.
- The script reads one source image and extracts these two column ranges:

```python
image[:, 1500:(1500 + 1700)]
image[:, (5120 + 1500):(5120 + 1500 + 1700)]
```

- The two crops are combined with `np.hstack`.
- The script supports custom output path and optional crop parameters:

```powershell
py tools\extract_camera_pair.py input.bmp -o output.bmp
```

- Added boundary checks so an image that is too narrow fails with a clear error instead of silently producing a bad crop.

## Neck Reflector Span Check

- Removed the old `max_pair_offset_std_px` configuration and related `pair_offset_px` consistency checks.
- Added `neck_reflector_x_span_max_diff_px` under `[VisionNeck]` in `src/cnf.ini`.
- In Neck mode, after detecting `reflector1` and `reflector2`, the engine now calculates each reflector span as:

```python
abs(left_boundary[0] - right_boundary[0])
```

- The engine compares the span difference between Camera 1 and Camera 2.
- Added diagnostics:
  - `reflector_x_span_camera1_px`
  - `reflector_x_span_camera2_px`
  - `reflector_x_span_diff_px`
- If the difference exceeds `neck_reflector_x_span_max_diff_px`, Neck measurement is rejected with a message showing camera1 span, camera2 span, diff, and maximum.

## Diagnostics P90 Changes

- Changed reflector side-score diagnostics from mean to p90:
  - `side_score_mean` -> `side_score_p90`
  - `reflector_side_score_mean_camera1/2` -> `reflector_side_score_p90_camera1/2`
- `side_score_p90` is calculated with:

```python
np.percentile(side_score, 90)
```

- Changed Crown meniscus column-strength diagnostics from mean to p90:
  - `column_strengths_mean` -> `column_strengths_p90`
  - `crown_column_strengths_mean_camera1/2` -> `crown_column_strengths_p90_camera1/2`
- `column_strengths_p90` is calculated with:

```python
np.percentile(column_strengths, 90)
```
