# 2026-07-02 Work Log

## Calibration 页面 UI 文件化

- 按 Sorter 页面模式调整 `Calibration` 页面结构。
- 新增 `src/modules/PageCalibration.ui`，主页面静态布局迁移到 `.ui` 文件。
- 新增 `src/modules/Ui_PageCalibration.py`，页面类通过 `Ui_PageCalibration.setupUi(self)` 加载布局。
- `src/modules/page_calibration.py` 不再手写 `QSplitter`、`QFrame`、`QGridLayout`、`QPushButton` 等静态布局。
- `page_calibration.py` 现在只保留：
  - 页面初始化
  - 事件绑定
  - `cnf.ini` 参数同步
  - 图像加载/显示
  - 在线 alive/frozen 逻辑
  - 角点检测和标定逻辑

## UI 布局与边框

- 参考 `PageCamera.ui` 的 `QSplitter + QFrame` 风格。

## 参数读取方式

- `PageCalibration` 的 `cnf.ini` 参数读取方式改为参考 `PageCamera.update_param`。
- `_load_config()` 按行解析 `cnf.ini`，去掉旧项目参数值外层的 `[]`。
- 初始化读取和 Parameters 页面更新都统一走 `update_param(IniEntry)`。
- `update_param()` 内部使用 `param_map` 根据 `group/key` 映射到 `CalibrationSettings` 属性。

## 中心点角点检测流程

- 删除每张图每个相机需要两个 seed 的旧逻辑。
- 改为每个相机只需要一个中心点：
  - 在视图中点击棋盘中心区域。
  - 点击 `Use Center 1` 或 `Use Center 2` 保存该相机中心点。
  - 重复点击会覆盖原中心点。
- 中心状态显示从 `0/2` 改为 `0/1`。
- `_detect_chessboard_from_center()` 使用单中心点进入手动检测。
- 新增 `_center_four_from_seed()`：
  - 在中心点附近半径内搜索角点候选。
  - 自动选出最像中心 `2x2` 的四个角点。
  - 使用这四个角点建立初始网格。
  - 再按棋盘网格关系向四周外推角点。
- 删除旧的 `_center_four_from_seeds(seed1, seed2)` 逻辑。

## 后续注意

- 当前环境没有 `pyside6-uic`，因此 `Ui_PageCalibration.py` 是按 Qt uic 输出风格手动补齐的。
- 后续如果用 Qt Designer 修改 `PageCalibration.ui`，需要在有 PySide6 的环境中重新生成 `Ui_PageCalibration.py`。
- 单中心点自动选中心四角依赖中心附近角点质量；现场测试时需要观察预览图中的角点数量和位置是否合理。
