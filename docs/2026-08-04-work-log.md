## Auto Exposure

- Added global auto exposure parameters under `[Camera]`:

```ini
auto_exposure_enabled = [0]
auto_exposure_target = [120]
auto_exposure_min_us = [1000]
auto_exposure_max_us = [50000]
auto_exposure_gain = [0.2]
auto_exposure_deadband = [3]
auto_exposure_interval_ms = [500]
```

- Auto exposure uses ROI mean gray value as the feedback value.
- Exposure is adjusted by proportional control:

```text
next_exposure = current_exposure * (1 + gain * (target_gray - mean_gray) / target_gray)
```

- The result is clamped to `auto_exposure_min_us..auto_exposure_max_us`.
- `auto_exposure_deadband` prevents small gray-value fluctuations from constantly changing exposure.
- PageCamera emits `camera_exposure_changed` after each frame so other pages can display the current exposure.

## ROI Ownership

- Home/Online auto exposure ROI moved to `[Measurement]`:

```ini
auto_exposure_roi_camera1 = [0,0,512,512]
auto_exposure_roi_camera2 = [0,0,512,512]
```

- Calibration continues to use existing `[Calibration]` ROI:

```ini
camera1_roi = [2000,1300,1200,1600]
camera2_roi = [2000,1800,1200,1600]
```

- PageCamera selects ROI by camera owner:
  - `online`: uses `[Measurement] auto_exposure_roi_camera1/2`
  - `calibration`: uses `[Calibration] camera1_roi/camera2_roi`

## Page Behavior

- Home image info labels now include exposure:

```text
Pos (x,y) | G gray | Light value | Exp exposure_us us
```

- Calibration image info labels now include exposure:

```text
View N - Pos: (x, y) | Value: gray | ROI mean: value | Exp: exposure_us us
```

- Home draws the blue auto exposure ROI rectangle only when:
  - runtime mode is Online
  - `auto_exposure_enabled = [1]`

- Calibration always draws the blue Calibration ROI rectangle when an image is displayed.
- Changing `camera1_roi` or `camera2_roi` refreshes the current Calibration image overlay.
- Home keeps the latest measurement overlay and appends the ROI rectangle instead of replacing existing measurement contours.

## Online Stage Rule

- Online auto exposure is enabled only during:
  - `MeasurementStage.IDLE`
  - `MeasurementStage.NECK`

- During `crown`, `body`, and `endcone`, exposure remains unchanged.
- `IDLE` still uses the Neck processing path, but with the longer idle sample period.
- Added `online_stage_changed` signal so PageHome can notify PageCamera of the current PLC stage.
